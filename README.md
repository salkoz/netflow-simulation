## 🎯 Назначение

NetFlow NOC Simulator — это зрелищный инструмент для визуализации и демонстрации:
- **Сетевого трафика** в реальном времени с маршрутизацией пакетов
- **DDoS-атак** и их воздействия на инфраструктуру
- **Firewall-защиты** с интерактивным включением/выключением
- **Chaos Engineering** — обрыв каналов связи и восстановление
- **Авто-балансировки нагрузки** между резервными маршрутами
- **Телеметрии** и live-мониторинга производительности сети

Идеально подходит для:
- Презентаций на хакатонах и конференциях
- Демонстрации принципов работы сетевой инфраструктуры
- Обучения основам кибербезопасности и отказоустойчивости
- Визуализации Chaos Engineering практик

## 🏗️ Архитектура модулей

Проект построен на чистой модульной архитектуре с разделением ответственности:

### `src/types.ts`
Определяет все типы данных системы:
- `NodeType` — типы сетевых узлов (client, router, firewall, server)
- `NetworkNode` — узел сети с координатами и состоянием
- `NetworkLink` — канал связи с параметрами capacity/latency
- `Packet` — пакет данных (normal/ddos) в полёте
- `SimulationStats` — метрики производительности
- `EventLogItem` — события системы
- `VisualEffect` — визуальные эффекты (block/drop/reroute)

### `src/presets.ts`
Готовые топологии сети:
- **basicNetwork** — простая топология: Client → Firewall → 2 Routers → Server
- **enterpriseNetwork** — корпоративная сеть: 2 Clients → 2 Firewalls → 2 Routers (cross-linked) → 2 Servers

### `src/simulation.ts`
**SimulationEngine** — ядро симуляции:
- `tick(deltaTime)` — основной игровой цикл
- `toggleFirewall(nodeId)` — включение/выключение защиты
- `toggleLinkBroken(linkId)` — обрыв/восстановление канала
- `setDdos(active)` — запуск/остановка DDoS-атаки
- `setAutoBalance(active)` — авто-балансировка нагрузки
- `setSpawnRate(rate)` — интенсивность трафика (1-30 pkt/s)

**Логика работы:**
- Генерация пакетов от клиентов к серверам
- Маршрутизация с учётом разорванных каналов
- Фильтрация DDoS-пакетов на файрволах
- Балансировка по загруженности каналов
- Обработка перегрузок (capacity exceeded)
- Генерация системных событий с анти-спам кулдауном

### `src/components/NetworkCanvas.tsx`
Визуализация сети на HTML5 Canvas (800×500):
- **Тёмная кибер-сетка** в стиле радара NOC
- **Динамическая окраска каналов** по загрузке (зелёный → жёлтый → красный)
- **Анимация пакетов** с неоновым свечением и шлейфом
- **Визуальные эффекты** блокировки/потери пакетов
- **Интерактивность:**
  - Клик по firewall — toggle защиты
  - Клик по каналу — обрыв/восстановление
  - Hover — подсказки с параметрами
- 60 FPS через requestAnimationFrame

### `src/components/TrafficChart.tsx`
Live-график телеметрии:
- Зелёная кривая — доставленные пакеты/сек
- Красная кривая — потерянные пакеты/сек
- Окно 30 секунд с автомасштабированием
- Легенда и оси координат

### `src/App.tsx`
Главный NOC/Cyber-Defense интерфейс:
- **Выбор пресета** (Basic/Enterprise)
- **Кнопка "Run 15s Demo"** — автоматический сценарий:
  - 0–3с: нормальный трафик
  - 3с: старт DDoS + обрыв главного канала
  - 8с: авто-включение Firewall + Auto-Balance
  - 15с: завершение демо
- **Управление:**
  - Start/Pause/Reset
  - Тумблеры DDoS Attack и Auto-Balance
  - Слайдер интенсивности трафика (1–30 pkt/s)
- **Метрики:** Delivered, Dropped, Blocked by Firewall, Avg Latency
- **Event Log** — прокручиваемый лог событий с цветовым кодированием

## 🎮 Интерактивные фичи

1. **Клик по узлу Firewall** — включает/выключает DDoS-защиту (зелёный = ON, серый = OFF)
2. **Клик по каналу связи** — обрывает/чинит кабель (красный пунктир = OFFLINE)
3. **Hover на узлах/каналах** — показывает tooltip с параметрами и подсказкой действия
4. **DDoS Attack toggle** — запускает атаку (75% трафика становится вредоносным)
5. **Auto-Balance toggle** — включает умную маршрутизацию по наименьшей загрузке
6. **Traffic Intensity slider** — регулирует интенсивность генерации пакетов
7. **Run 15s Demo** — запускает автоматический сценарий для эффектной презентации

## 🚀 Команды запуска

### Установка зависимостей
```bash
npm install
```

### Запуск dev-сервера
```bash
npm run dev
```
Откроется по адресу `http://localhost:5173`

### Сборка production-версии
```bash
npm run build
```
Результат в папке `dist/`

### Preview production-сборки
```bash
npm run preview
```

| 3с    | 🔴 Старт мощного DDoS-атаки (75% вредоносных пакетов) |
| 3с    | ⚠️ Обрыв главного канала связи (chaos injection) |

| 8с    | ⚖️ Включение Auto-Balance (умная маршрутизация) |
| 8–15с | ✅ Стабилизация сети, блокировка атаки |
